# 20 November 2026 — The World in One Day

A newspaper front page summing up 20 November 2026 in a single 1024×1024 image: six stories that defined the day — the Shenzhen peace summit, the strike on Kyiv, the ICJ verdict on Myanmar, the Hormuz blockade, the AI stock sell-off, and the magnitude 6.7 quake in Peru. The image is drawn with Python (PIL) in `draw.py` and shipped as `entry.png`; `main.py` copies it to the output directory.
