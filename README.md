# 20 November 2026 — The World in One Day (round 2)

A newspaper front page summing up 20 November 2026 in a single 1024×1024 image: six stories that defined the day — the Shenzhen peace summit, the strike on Kyiv, the ICJ verdict on Myanmar, the Hormuz blockade, the AI stock sell-off, and the magnitude 6.7 quake in Peru.

Round 2 redesign: the two biggest stories (Shenzhen, Kyiv) get large hero panels, and every panel's key number is the loudest element (400+ drones, 110 missiles, −3.7%, 6.7, 3 leaders, 1st genocide verdict). The image is drawn with Python (PIL) in `draw.py` and shipped as `entry.png`; `main.py` copies it to the output directory.
